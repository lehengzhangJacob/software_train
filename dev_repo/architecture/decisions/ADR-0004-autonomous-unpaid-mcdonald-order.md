# ADR-0004：Agent 自主创建未支付麦当劳订单

- 状态：accepted
- 日期：2026-08-16
- 合同：C-06-L1

## 背景

课程项目需要展示从营养建议到真实点餐的产品闭环。麦当劳中国官方 MCP 可以提供地址、门店、菜单、营养、计价、创建订单和订单查询能力；创建订单后由用户通过支付入口自行完成支付。

## 决策

1. 当前用户消息必须明确表达麦当劳点餐意图，才会进入自动选餐流程。
2. Agent 可以结合档案、近期餐食、长期记忆、菜单营养和价格选择商品。
3. 每条用户请求最多调用一次创建订单，并且只能创建未支付订单。
4. 支付链接只作为当前响应的临时结果交给用户，不进入消息、记忆、数据库或日志。
5. 麦当劳 Token 由本机 Secret Store 持有，不进入模型上下文。
6. 无有效地址、门店、菜单、计价或 Token 时停止建单并说明原因。

## 不做

- 不调用支付工具，不自动打开或确认支付。
- 不从普通营养咨询、模糊表达或历史消息推断点餐授权。
- 不创建后台订单，不重试形成第二笔订单。
- 不持久化支付链接、支付凭据或麦当劳 Token。

## 验证

- 同一测试用例证明普通营养咨询不调用 `create-order`，明确点餐请求最多调用一次。
- 假 MCP 覆盖菜单、结构化选餐、计价、建单和支付入口返回。
- 扫描 AgentMessage、MemoryItem、日志和 API 持久化数据，确认没有 Token 或支付链接。
