# ADR-0001：私有单用户课程项目边界

- 状态：accepted
- 日期：2026-07-10
- 合同：C-02-A1

## 背景

现有代码具备多个业务页面，但没有认证、多租户、托管数据库或公网运维能力。用户确认本项目只用于课程展示，不是公网 SaaS。

## 决策

1. 保持 Next.js 单仓库全栈与 SQLite。
2. 应用只呈现一个 primary profile，所有业务 API 在服务端绑定该档案。
3. 个性化页面强制动态渲染。
4. Prisma migration 成为 schema 唯一生产真相。
5. AI 仅经服务端代理；餐食识别必须审核后保存。
6. 交付口径是本机可复现运行与课程演示，可选单实例容器。
7. /api/meals 批量保存 items[]，/api/exercise/suggest 支持采用与取消，报告输出连续自然日；这些接口增量由后续切片实现。

## 后果

- 不增加 Auth.js、OAuth、用户注册或云数据库复杂度。
- 应用不能被表述为安全的公网多用户产品。
- 未来若改变该边界，必须新开架构与 ER 修宪，并定义身份、所有权、迁移与隐私责任。
